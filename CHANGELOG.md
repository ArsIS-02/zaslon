# Изменения

## 1.3.0 — 2026-10-20

Новая реализация: панель и агент на хосте, без Docker на хостах.

- Агент на хосте (Python, только стандартная библиотека) вызывается по SSH одной принудительной командой через sudo; shell не используется.
- Порты, службы, firewalld, режим и булевы опции SELinux; каждое изменение откатывается таймером, если не подтвердить.
- Вход по паролю: форма и cookie-сессия, пароль хранится хэшем, смена пароля в интерфейсе, выход отзывает сессию на сервере.
- Установка агента одной командой из формы «Новый хост»: проверка сумм, установка сертификата панели (с заменой старого), регистрация хоста по одноразовому токену.
- Интерфейс на русском и английском, светлая и тёмная темы, раздел «Справка».

Предыдущая версия 1.1.0 (другая архитектура) сохранена в ветке `legacy-1.1.0`.
