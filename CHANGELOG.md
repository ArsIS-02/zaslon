# Изменения

## 1.0.0 — 2026-10-10

Первая публикация.

- Панель: обзор хостов, вкладка на каждый хост; разделы «Сводка», «Порты», «Зоны», «iptables», «nftables», «SELinux», «fail2ban», «Журнал».
- Таблица портов: зона ↔ слушающий процесс ↔ публикация Docker; замечания по firewall, SELinux, SSH и fail2ban.
- Изменения через очередь и транзакции на хосте: таймер отката, проверка доступа панели по SSH в текущей и сохранённой конфигурации, автоподтверждение новым соединением.
- Отчёт по хосту в HTML и PDF.
- Скрипты: диагностика хостов, подготовка (`sec_fw-admin`, helper, ключ с принудительной командой, fail2ban), установка панели.
- Вход по паролю, генерируемому при установке; без пароля — только локальный доступ.
- Образ: права на файлы приложения и пользователь с UID панели (нужен для `ssh`).
